# Contributing to Orange Client

Please open an issue in the repository where you obtained this fork before submitting a large change. Keep changes focused, run `cargo fmt --all` and the relevant tests, and include steps to reproduce bug fixes.

This repository is a GPL-3.0-only derivative of OneLauncher / OneClient. Preserve the upstream license and attribution notices in redistributed source and binaries. Do not use Polyfrost trademarks or assets as Orange Client branding.
